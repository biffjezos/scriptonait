        Sampling settings
        

          
          
          
          
          
        

        

          Temperature 0 is greedy and repeatable. Top-k and top-p cut the
          long tail of unlikely tokens, which is what keeps a small model's
          sentences from derailing.
        

      

    


    

      
Use your own material

      

        Add scripts, chapters or notes. They're used two ways: as context
        for what you ask for, and — if you want — as fine-tuning data.
        Everything stays in your browser.

Fine-tune on your material

      

        Optional, and the slowest thing on this page: this is real
        training — forward pass, backward pass, optimizer — and it runs on
        your CPU even when generation is running on your GPU, because
        only the generation kernels are written in WGSL.
      

      

        It does not train a model from nothing. The model this page loads
        was already trained, on a GitHub Actions runner, from the
        public-domain books and plays listed in
        corpus/manifest.tsv — hours of it, off your machine.
        Fine-tuning bends that model a little toward whatever you add
        above.
      


      

        
        
        
        
      


      

        
        
      


      

        

        

      

      
    


    

      
The model

      

      

        
        
      

      

        A model file carries its own tokenizer, so it's the only thing you
        need to keep. Fine-tuned copies save from here.
      

      

        Start over with an untrained model
        

          Trains from scratch on your own sources only. Expect it to take a
          long time and to write badly until it has seen a lot of text —
          this is the path the shipped model exists to save you from.
        

        

          
          
          
          
          
          
        

        
      

    

  


  

    

    

      Everything runs locally. The model is a few million parameters — it
      picks up voice, format and structure, not long-range plot. See the
